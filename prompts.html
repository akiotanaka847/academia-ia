Copia, pega y ajusta

Pulsa Copiar, pega el prompt en tu herramienta (ChatGPT, Claude, Gemini o dentro de un agente en n8n / Workfront Fusion) y reemplaza los [corchetes]. Para tareas serias, baja la temperatura y verifica el resultado (Módulos 31 y 32).

1 · Comunicación y redacción

Escribir, resumir y reescribir más rápido, sin perder tu tono.

Cuándo: tienes un texto largo y necesitas lo esencial.

Resumen ejecutivo
Actúa como asistente ejecutivo. Resume el siguiente texto para una
persona ocupada, en máximo 5 viñetas. Incluye solo lo accionable
(decisiones, riesgos y próximos pasos). Si hay cifras clave, consérvalas.

Texto:
"""
[pega aquí el texto]
"""

Cuándo: redactar un correo profesional en segundos.

Correo profesional
Escribe un correo en tono [cordial y profesional] para [destinatario]
sobre [tema]. Objetivo del correo: [qué quiero lograr].
Máximo 120 palabras, con un asunto claro y una llamada a la acción
al final. No uses relleno.

Cuándo: el texto está, pero el tono no.

Reescribir en otro tono
Reescribe el siguiente texto en un tono más [claro y cercano],
manteniendo el significado y los datos. Evita tecnicismos innecesarios
y frases largas. Devuélvelo listo para enviar.

Texto:
"""
[pega aquí el texto]
"""

2 · Análisis y datos

Convertir texto desordenado en información estructurada y decisiones.

Cuándo: necesitas datos limpios que otra herramienta pueda usar.

Extraer datos a JSON
Extrae del siguiente texto estos campos y devuélvelos SOLO como JSON
válido, sin explicación. Si un campo no aparece, ponlo como null.

Campos: { "cliente": "", "total": "", "moneda": "", "vencimiento": "" }

Texto:
"""
[pega aquí el texto]
"""

Cuándo: clasificar muchos elementos igual y en serie.

Clasificar
Clasifica cada mensaje en una de estas categorías: [Urgente, Normal, Spam].
Responde SOLO con la categoría, una por línea, en el mismo orden.

Mensajes:
1. [texto]
2. [texto]
3. [texto]

Cuándo: decidir entre opciones con criterios claros.

Comparar opciones
Compara [opción A] y [opción B] para mi caso: [contexto].
Devuélvelo en una tabla con estos criterios: costo, tiempo,
riesgo y facilidad. Al final, una recomendación en una frase
con su porqué.

3 · Gestión de proyectos y Workfront

Plantillas pensadas para el día a día en Adobe Workfront y equipos de proyecto.

Cuándo: preparar el estado semanal de un proyecto.

Resumen de estado (Workfront)
Actúa como gestor de proyectos. Con estos datos exportados de Workfront
(tareas, responsables, fechas y avances), redacta un resumen de estado
para dirección con esta estructura fija:

• Avance general (una línea con % aproximado)
• Logros de la semana
• Riesgos y bloqueos (con responsable)
• Próximos pasos

Sé concreto y no inventes datos que no estén.

Datos:
"""
[pega aquí el export de Workfront]
"""

Cuándo: convertir notas sueltas en una actualización para dirección.

Actualización para stakeholders
Convierte estas notas de avance en una actualización breve para
[dirección/cliente], en 4 líneas máximo, tono claro y positivo pero
honesto con los riesgos. Sin jerga interna.

Notas:
"""
[pega aquí tus notas]
"""

Cuándo: descomponer un objetivo grande en tareas de Workfront.

Desglosar en tareas
Descompón este objetivo en una lista de tareas accionables para cargar
en Workfront. Para cada tarea da: nombre corto, una descripción de una
línea, un rol responsable sugerido y una estimación en horas.
Devuélvelo como tabla.

Objetivo: [describe el objetivo del proyecto]

Cuándo: escribir una descripción de tarea clara a partir de una idea vaga.

Descripción de tarea
Escribe una descripción de tarea clara para Workfront a partir de esta
idea: [idea]. Incluye: qué hay que hacer, resultado esperado (definición
de "hecho") y cualquier dependencia. Máximo 80 palabras.

4 · Prompts de sistema para agentes

La base de un agente confiable (Módulos 12 y 15): rol, límites y formato.

Cuándo: montar un asistente que responde con TUS datos.

Agente de soporte (RAG)
Eres el asistente de [empresa/equipo]. Respondes preguntas usando ÚNICAMENTE
la información del contexto que se te entrega. Reglas:
- Si la respuesta no está en el contexto, di: "No lo sé con la información que tengo".
- Cita de qué documento sale cada dato.
- Tono: [profesional y cercano]. Idioma: español.
- Nunca inventes datos, precios ni fechas.

Cuándo: un agente que devuelve datos para otra automatización.

Agente extractor (salida fija)
Eres un extractor de datos. Recibes texto y devuelves SIEMPRE un JSON válido
con exactamente estos campos, sin ningún texto adicional antes o después:

{ "asunto": "", "prioridad": "alta|media|baja", "accion_requerida": true }

Si un dato no se puede determinar, usa null. No expliques tu razonamiento.

5 · Técnicas avanzadas

Patrones que suben la calidad (Módulo 02). Combínalos con los de arriba.

Pocos ejemplos (few-shot): le muestras el criterio en vez de explicarlo.

Few-shot
Clasifica el sentimiento del comentario en: Positivo, Neutral o Negativo.

Ejemplos:
"Me encantó la atención" -> Positivo
"Llegó tarde pero funciona" -> Neutral
"Un desastre, no lo recomiendo" -> Negativo

Comentario: "[pega aquí]"

Cadena de pensamiento: para tareas con lógica o cálculo.

Razonar paso a paso
Resuelve el siguiente problema. Primero razona paso a paso de forma breve,
y al final da la respuesta en una línea que empiece con "Respuesta:".

Problema: [describe el problema]

Interacción invertida: deja que la IA recolecte el contexto que le falta.

Que te pregunte primero
Quiero que me ayudes a [objetivo]. Antes de responder, hazme las
preguntas que necesites para tener todo el contexto. Cuando tengas
suficiente, dímelo y entonces genera el resultado.
